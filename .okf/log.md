## 2026-07-31
* **SHf recovered — profile-caused, not the game update**: Superseding the same-day triage bullet below: no-profile injection works on the patched exe on multiple backends, so the update-broke-the-bootstrap theory was wrong. The crashes were the first-person profile doing full-GUObjectArray walks and stereo-view-offset Lua callbacks; fixed profile-side ([details](games/silent-hill-f.md)): a first-loading `00_settle.lua` gate (NTFS loads `_`-prefixed scripts LAST — digit prefixes load first), the lantern class scan disabled, stereo-view Lua registrations dropped (heap corruption under the AFW dispatch), cold-start AFW mode 2. Validated: solid 90 fps in AFW, first person, weapon switching clean, on backend `54c5f9d3…`. SHf is UE 5.4.2, not 5.7. Backend follow-up: make the AFW-path Lua stereo-view dispatch safe.
* **Avowed discovery-race fix**: Avowed abruptly failed every launch (three distinct signatures, two builds, across a reboot, zero on-disk changes) — a latent startup race in baseline offset discovery, which disassembles vtable entries UEVR has already hooked. Fixed by porting the minimal two-commit SDK discovery cache onto the baseline UESDK pin (local submodule branch `cache-on-baseline`); rejected the third cache commit for a per-frame FSceneViewFamily rescan performance regression. Also fixed the shrunken-menu `no_tag` ImGui state and the stale `CommitHash.autogenerated` guard. See [SDK discovery cache port](fixes/sdk-discovery-cache-port.md); validated backend `54c5f9d3…`. **Open**: cache commits are local-only; superproject gitlink uncommitted.
* **SHf regression triage**: [Silent Hill f](games/silent-hill-f.md) crashes at load since the 2026-07-23 Steam game update — one day after alpha.2 validation. A/B on branch `shf-uesdk-ab` proved the SH2 unification's UESDK pin is not the cause (identical crash on baseline `491f973a` and hardened `9034a857`); recovery needs the UE5.7 bootstrap re-derived against the patched exe. The A/B also re-broke SH2 (pre-world freeze), empirically re-confirming the baseline pin for the shipped branch.
* **Toolchain migration**: A VS auto-update removed MSVC 14.37 / SDK 10.0.22000; after a full `build/` wipe and reconfigure on MSVC 14.44 / SDK 10.0.26100, the rebuilt shipped source (backend `b72b72ae…`) was confirmed working for SH2. Recorded in [Silent Hill 2](games/silent-hill-2.md); the 14.37 pair is preserved as `UEVRBackend.shipped-unified.dll`/`.pdb`.
